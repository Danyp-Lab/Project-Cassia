# LiquidGlass Theme for Linux Mint

LiquidGlass is a sleek, dark, and modern theme designed specifically for the Cinnamon desktop environment. It brings a subtle "frosted glass" aesthetic to your panels, menus, and applications, giving your system a polished, premium feel.

## How to Apply the Theme

1. Open the **System Settings** on your computer.
2. Click on **Themes**.
3. Change the following settings to apply the full LiquidGlass look:
   * **Window borders:** Click and select **LiquidGlass**
   * **Applications:** Click and select **LiquidGlass**
   * **Desktop:** Click and select **LiquidGlass**

That's it! Your system will instantly update with the new style.

*Tip: If you don't see the changes immediately, you can press `Alt + F2`, type `r`, and press `Enter` to refresh your desktop.*
